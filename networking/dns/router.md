# Routers and DNS
This file contains some information I collected in regards to routers, dns and homelabbing / home networking.

## Speedport
The Speedport Smart 4 Plus router doesn't allow local dns servers.
Therefore any dns services need to be added manually to a device and the auto dns discovery needs to be disabled.

## FRITZ!Box
All FRITZ!Box routers seem to allow a single local dns server.
This needs to be verfied, since I don't currently have a FRITZ!Box router.
